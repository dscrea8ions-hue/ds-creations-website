# DS Creations Website

A premium royal-blue and gold Next.js website starter for DS Creations.

## Included pages

- Home
- About
- Products
- Bulk Quote
- Contact
- Responsive mobile navigation
- Floating WhatsApp button
- Royal blue, navy, gold and white brand system

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before going live

1. Add final product photographs.
2. Replace the temporary DS text monogram with the final royal-blue logo.
3. Connect the quotation form to email or a database.
4. Add Google Maps after confirming the complete postal address.
5. Add privacy policy and terms pages.
6. Deploy to Vercel and connect the final domain.
